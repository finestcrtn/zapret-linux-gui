Zapret Linux GUI

DPI bypass manager for Linux. Self-contained Flatpak: downloads zapret on first launch, installs an isolated daemon behind one admin prompt, and never touches an existing zapret install.

Click to install

No software center? Run:

flatpak install --user --from https://finestcrtn.github.io/zapret-linux-gui/zapretgui.flatpakref

Then launch Zapret Control from your app menu.
